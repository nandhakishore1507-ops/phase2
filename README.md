# 🧮 Smart Calculator

## 📌 About the Project

Smart Calculator is a simple and responsive web-based calculator developed as part of my Frontend Development Internship – Phase 2.

The application performs basic mathematical operations using HTML, CSS and JavaScript. It provides an interactive user interface with button controls and keyboard support.

## 🎯 Objectives

- Understand JavaScript fundamentals.
- Learn DOM manipulation and event handling.
- Implement mathematical operations.
- Develop an interactive user interface.
- Practice responsive web design.
- Improve frontend development skills.

## 🛠️ Technologies Used

- **HTML5** – Creates the calculator structure.
- **CSS3** – Provides styling and responsive design.
- **JavaScript** – Handles calculations and user interactions.
- **Visual Studio Code** – Code editor.
- **Git & GitHub** – Version control and project hosting.

## ✨ Features

- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Modulo (%)
- Clear all (AC)
- Delete last digit (DEL)
- Decimal number support
- Keyboard input support
- Responsive design
- Error handling for invalid calculations

## ▶️ How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Start performing calculations.
